GPS 실제 연동 매뉴얼 & API 가이드

다양한 기기(스마트폰, 트래커 앱, IoT 모듈)를 GeoLive 서버에 연결하는 방법

관제 대시보드
1

방법 1: 스마트폰 웹 브라우저 (앱 설치 불필요, 10초 완료!)

별도의 앱을 다운로드할 필요 없이 스마트폰의 Safari, Chrome 등의 브라우저에서 HTML5 Geolocation API 센서를 활성화하여 실시간 위치를 서버로 쏩니다.

접속 주소: http://[컴퓨터_IP]:8080/tracker.html?deviceId=기기ID&secretKey=보안키
특징: 화면 켜짐 유지(WakeLock) 내장, 1~10초 주기 설정 가능, 즉시 지도에 위치 표시
  1. 스마트폰과 관제 서버를 실행 중인 PC를 동일한 Wi-Fi 네트워크에 연결합니다.
  2. 대시보드 상단의 [내 폰 GPS 연동] 버튼을 눌러 나타나는 QR 코드를 스마트폰 카메라로 스캔합니다.
  3. 브라우저에서 "위치 정보 제공 허용"을 승인하고 [GPS 실시간 전송 시작] 버튼을 누릅니다.
2

방법 2: Traccar Client 전용 앱 (스마트폰 백그라운드 추적)

화면을 끄거나 다른 앱(유튜브, 네비게이션)을 실행 중일 때도 백그라운드에서 주기적으로 위치를 수신하고 싶다면 전 세계 표준 GPS 트래커 앱인 Traccar Client(무료)를 사용하십시오.

앱 다운로드
• Android: 구글 Play 스토어에서 "Traccar Client" 검색
• iOS: 애플 App Store에서 "Traccar Client" 검색
앱 내 설정 값
• 서버 주소: http://[서버IP]:8080/api/gps/osm
• 기기 식별자: 등록한 기기 ID (예: DEV-CAR-101)
• 위치 주기: 3 또는 5 초
• 상태(서비스 상태): ON으로 토글
3

방법 3: 하드웨어 GPS 모듈 (ESP32, 아두이노, 차량용 OBD)

LTE-M 모뎀이나 Wi-Fi가 탑재된 마이크로컨트롤러(ESP32 + NEO-6M GPS)를 사용해 차량이나 자전거에 상시 장착할 수 있습니다.

// ESP32 C++ HTTP POST Sample
#include <WiFi.h>
#include <HTTPClient.h>

void sendGpsLocation(float lat, float lng, float speed) {
  HTTPClient http;
  http.begin("http://192.168.0.50:8080/api/gps/update");
  http.addHeader("Content-Type", "application/json");

  String json = "{\"deviceId\":\"DEV-CAR-101\",\"secretKey\":\"key-demo-car-101\""
                ",\"lat\":" + String(lat, 6) +
                ",\"lng\":" + String(lng, 6) +
                ",\"speed\":" + String(speed, 1) + "}";

  int httpCode = http.POST(json);
  http.end();
}
