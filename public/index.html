GPS 실제 연동 센터 (스마트폰 & 앱)

스마트폰, 전용 앱, IoT GPS 모듈을 실시간으로 연결하는 방법

✨ 별도의 앱 설치가 전혀 필요 없습니다!

스마트폰 기본 카메라로 아래 QR 코드를 스캔하거나 링크를 열면, 스마트폰의 실제 GPS 센서가 3초마다 현재 위치와 주행 속도를 이 지도 화면으로 실시간 쏩니다.
카메라로 스캔하세요
연동 대상 기기: 기기 선택됨
접속 서버 주소 (HTTPS 공개 주소 또는 Wi-Fi IP):

※ .env의 PUBLIC_URL 또는 Cloudflare 터널 주소가 기본값으로 자동 연동됩니다.

스마트폰 접속 링크:
스마트폰 연동 3단계:

1. 스마트폰 카메라로 위 QR코드 스캔 (또는 링크를 카톡/문자로 열기)

2. 브라우저에서 "위치 권한 허용" 팝업이 뜨면 [허용] 클릭

3. [ GPS 실시간 전송 시작 ] 버튼을 터치하면 이 화면에 즉시 동선이 나타납니다!

🌐 외부망(LTE / 5G / 다른 Wi-Fi) 및 HTTPS 연결 가이드

스마트폰 브라우저는 보안 정책상 HTTPS에서만 GPS 위치 수집을 허용합니다.
무료 Cloudflare Tunnel을 이용하면 공유기 포트포워딩 없이도 전 세계 어디서나 접속 가능한 안전한 HTTPS 임시 주소를 3초 만에 생성할 수 있습니다!
1단계: 터널 실행 명령어 (PowerShell 또는 CMD)
cloudflared tunnel --url http://localhost:8080

※ 프로젝트 폴더 내의 start_tunnel.bat을 더블 클릭하면 자동으로 실행됩니다!

2단계: 생성된 HTTPS 주소 확인 및 등록

터널이 실행되면 콘솔 창에 https://xxxx-xxxx.trycloudflare.com 주소가 나타납니다.
그 주소를 첫 번째 탭의 [컴퓨터 IP / 도메인 주소] 입력란에 붙여넣고 [적용]을 누르면 스마트폰 QR코드가 해당 주소로 즉시 변경됩니다!

무료 Traccar Client 앱 (백그라운드 상시 추적)

화면이 꺼져 있거나 다른 앱(유튜브, 내비게이션)을 실행 중일 때도 백그라운드에서 주기적으로 위치를 수신하고 싶다면 구글 플레이 또는 애플 앱스토어에서 "Traccar Client"(무료)를 설치하세요.

1. 서버 주소 (Server URL):
2. 기기 식별자 (Device Identifier):
3. 위치 수신 주기 (Frequency): 권장 3초 ~ 5초

차량용 GPS 추적기, 아두이노, ESP32, 라즈베리파이 등 임의의 기기에서 아래 HTTP REST API로 위치 데이터를 전송할 수 있습니다.

POST /api/gps/update
Content-Type: application/json
{
  "deviceId": "DEV-CAR-101",
  "secretKey": "key-demo-car-101",
  "lat": 37.5665,
  "lng": 126.9780,
  "speed": 45.2,       // km/h
  "altitude": 35.0,    // meters
  "bearing": 180.0,    // 0~360 degrees
  "accuracy": 3.5,     // meters
  "battery": 85        // 0~100 %
}
cURL 테스트 명령어: 
curl -X POST http://localhost:8080/api/gps/update -H "Content-Type: application/json" -d "{\"deviceId\":\"DEV-CAR-101\",\"lat\":37.5665,\"lng\":126.9780,\"speed\":30}"
